# 给老师的展示说明

## 这次展示的目标

这次展示不是证明“对联生成已经做到了很好”，而是展示：

1. 我已经把一个本地可跑的小模型基线做出来了  
2. 我又接入了一个预训练小模型 `Qwen3-0.6B-Base`  
3. 在同一份数据、同一组样例上，`LoRA 微调` 相比 `zero-shot` 和手写小模型，已经能看到明确改进

## 这次实验怎么做的

- 底模：`Qwen3-0.6B-Base`
- 数据：从原始对联训练集里，按规则粗筛出 `10000` 条
- 微调方式：`LoRA`
- 对照对象：
  - `Qwen zero-shot Prompt C`
  - 手写 `attention seq2seq` baseline
  - `LoRA E1`
  - `LoRA E4(best@epoch2)`
- 评测方式：固定 `10` 条 `7` 字上联，逐条人工对照

## 这轮结果能说明什么

可以说明两点：

1. **预训练小模型路线比手写小模型更有潜力**  
   和当前的 `attention baseline` 比，`Qwen + LoRA` 更少出现完全无关的模板句。

2. **微调是有实际意义的**  
   和 `zero-shot` 比，LoRA 版本更少直接复读上联，也更愿意输出“像下联”的句子。

## 这轮结果还不能说明什么

还不能说：

- 这个系统已经能稳定生成高质量对联
- 只要继续训就一定会很好
- 当前数据已经足够干净

因为目前还能看到：

- 语义有时会发散
- 对仗不够工整
- 个别样例仍然机械、怪异

## 最合理的结论

如果用一句话概括这轮实验：

> 这次实验已经证明了“预训练小模型 + LoRA 微调”这条路线是有效的，但离稳定高质量生成还有距离，下一阶段的关键不只是继续训练，更是进一步提升训练数据质量。

## 如果现场要口头说明

可以直接这样说：

> 我先做了一个手写小模型基线，然后再引入 Qwen3-0.6B 做 zero-shot 和 LoRA 微调对比。结果表明，LoRA 相比 zero-shot 已经明显减少了复读和跑偏，也比原来的 attention 小模型更贴近任务，但目前仍然受数据质量和对仗约束不足的影响，所以这轮更适合展示“路线成立”，而不是展示“最终效果已经成熟”。
